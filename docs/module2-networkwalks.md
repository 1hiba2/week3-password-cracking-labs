# Module 2 — Password Cracking with Networkwalks Tools

## Objective

Recover the password for the separate Networkwalks lab PDF using browser-based tools.

## Tools

- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- PDF viewer

## Steps I followed

1. Opened the Networkwalks Hash Calculator.
2. Extracted the hash from the password-protected lab PDF.
3. Entered the extracted hash into the Networkwalks Password Cracker.
4. Used the recovered password to open the PDF.
5. Viewed the congratulations page and recorded the flag.

## Result

- PDF successfully unlocked
- Flag: `nw{networkwalks_flag1_jtr_270521_1}`
